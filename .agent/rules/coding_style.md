# Coding Style

## General
- **Naming**: Use camelCase for variables/functions, PascalCase for types/components.
- **Comments**: Write comments in Korean (as requested).
- **Formatting**: Use Prettier/GoFmt.

## Frontend
- Functional Components with Hooks.
- Avoid inline styles where possible.

## Backend
- Handle errors explicitly (Go style).
- Use context for cancellation/timeouts.
