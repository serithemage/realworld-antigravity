# Make PR Workflow

## Prerequisites

## Workflow

1. 현재 커밋되지 않은 변경사항을 확인
2. 코드의 변경사항에 대해 리드미를 포함한 문서가 작성 또는 업데이트 되어 있는지 확인
3. 변경사항에 대한 이슈가 존재하는지 확인
4. 이슈에 대한 피처 브랜치가 존재하는지 확인
5. 이슈와 피처브랜치가 존재하지 않을경우 이슈를 생성하고 피처브랜치를 생성한다.
6. PR을 생성한다.
7. `gh-pr-review`명령을 사용하여 PR에 대한 리뷰를 생성한다. 리뷰에는 칭찬을 적지 말고 개선점을 중심으로 작성한다.
